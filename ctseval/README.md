# Clinical Time Series Evaluation (CTSEval)

CTSEval is a Python package for evaluating clinical time series predictions. It provides a set of metrics to assess the performance of time series prediction models, with a focus on clinical settings.

## Installation

You can install CTSEval using pip:

```bash
pip install ctseval
```

## Usage

To use CTSEval in your project, follow these steps:

1. Import the package:

```python
import ctseval
```

2. Use the `compute_metrics` function to evaluate your predictions:

```python
ctseval.compute_metrics()
```
